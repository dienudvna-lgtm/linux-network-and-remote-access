# Capaian Pembelajaran

Setelah menyelesaikan rangkaian latihan dan mengisi bukti praktik, siswa diharapkan mampu:

1. Memeriksa alamat dan status interface jaringan menggunakan `ip -br addr`.
2. Membaca default gateway dan route menggunakan `ip route`.
3. Memeriksa konfigurasi DNS melalui `resolvectl status` atau `/etc/resolv.conf`.
4. Menguji resolusi nama dengan `getent hosts` dan membedakan masalah DNS dari masalah konektivitas IP.
5. Mendiagnosis gangguan secara bertahap dari interface, gateway, tujuan IP, DNS, hingga layanan aplikasi.
6. Menjelaskan fungsi public key dan private key pada autentikasi SSH serta melakukan pengujian login kunci secara aman.
7. Memeriksa dan mengatur firewall menggunakan UFW bila tersedia dan sesuai, dengan hanya mengizinkan layanan yang diperlukan.
8. Mencatat perintah, keluaran aktual, tangkapan layar, kendala, dan refleksi praktik secara jujur.

## Indikator Bukti

- Catatan tiap lab memuat perintah dan output yang benar-benar diperoleh.
- Screenshot disimpan dengan nama yang dicantumkan dalam catatan masing-masing lab.
- Tidak ada private key atau rahasia akses yang dimasukkan ke dokumentasi maupun diunggah.
- Perubahan konfigurasi hanya dilakukan setelah kondisi awal diperiksa dan risiko akses dipahami.
